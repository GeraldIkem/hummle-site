# hummle.app

The public website for Hummle, a private read-aloud app that runs on your own computer.

This repository holds only the static website files served at https://hummle.app via GitHub Pages.
The Hummle app itself is developed separately and is not part of this repository.

- Fonts: Fraunces, Atkinson Hyperlegible Next, Literata and Kalam, under the SIL Open Font License 1.1 (see `fonts/licences/`).
- Voice portraits are AI-generated (see `CREDITS.md`); they are not photographs of real people.
- No cookies, analytics or third-party scripts.
